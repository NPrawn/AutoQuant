# AutoQuant 시연 시나리오

> 목적: 사용자가 투자 아이디어를 전략으로 만들고, 과거 데이터로 검증한 뒤, 모의투자로 이어지는 흐름을 보여 준다.
> 작성 기준: 현재 구현된 Frontend 경로와 Backend API.

## 1. 시연 전 준비

| 항목 | 준비 내용 |
| --- | --- |
| 로그인 | SSAFY SSO 로그인 완료 상태로 브라우저를 준비한다. |
| 전략 | 자연어로 생성한 전략 1개와 백테스트 완료 전략 1개를 준비한다. |
| 백테스트 | 결과 화면에서 즉시 보여 줄 `COMPLETED` 실행 1건을 준비한다. |
| 모의투자 | 보유 종목·체결 내역이 있는 `RUNNING` 또는 완료된 실행 1건을 준비한다. |
| 네트워크 | Upbit 시세와 GMS 호출이 가능한 운영 환경에서 진행한다. |
| 화면 | 브라우저 확대 비율 100%, 알림·개발자 도구·개인 정보가 보이지 않도록 정리한다. |

백테스트는 실제 계산 시간이 있으므로, 발표 중 새 요청을 실행하되 결과 설명은 사전에 완료된 실행을 사용한다. 실행 상태가 `QUEUED → RUNNING → COMPLETED`로 바뀌는 모습만 짧게 보여 준다.

## 2. 전체 흐름

```text
홈에서 투자 아이디어 입력
→ AI 전략 초안 생성
→ 전략 블록 검토·저장
→ 백테스트 요청 및 결과 확인
→ 모의투자 시작 또는 실행 결과 확인
```

## 3. 화면별 상세 시나리오

### 장면 1. 로그인과 홈

| 항목 | 내용 |
| --- | --- |
| 진입 경로 | `/login` → SSAFY 로그인 → `/` |
| 조작 | 로그인 후 홈의 자연어 입력창에 투자 아이디어를 입력한다. |
| 예시 문장 | `거래량이 늘고 최근 수익률이 높은 코인 5개를 매일 다시 선정하고 싶어` |
| 확인 포인트 | “투자 아이디어를 전략으로”라는 홈 문구와 자연어 입력 기반 진입을 보여 준다. |
| 발표 멘트 | “사용자는 지표식을 직접 작성하지 않고 투자 아이디어를 문장으로 입력합니다.” |

### 장면 2. AI 전략 초안 생성

| 항목 | 내용 |
| --- | --- |
| 진입 경로 | 홈 입력창 → `전략 만들기` → `/strategies/new` |
| 조작 | AI 변환 기능을 실행하고 생성된 조건·순위·선정 종목 수·리밸런싱 주기를 확인한다. |
| 확인 포인트 | 자연어가 전략 DSL 기반 블록으로 변환되며, 사용자가 값과 조건을 검토·수정할 수 있음을 보여 준다. |
| 발표 멘트 | “AI는 전략 초안을 만들고, 실제 실행 규칙은 사용자가 확인할 수 있는 JSON DSL로 저장됩니다.” |

### 장면 3. 전략 저장과 상세 화면

| 항목 | 내용 |
| --- | --- |
| 진입 경로 | 전략 빌더 → 저장 → `/strategies/{strategyId}` |
| 조작 | 전략 이름을 입력하고 저장한 뒤, 전략 상세에서 조건 요약과 실행 버튼을 확인한다. |
| 확인 포인트 | 전략 수정은 기존 내용을 덮어쓰기보다 새 버전으로 저장되어 실행 이력을 구분할 수 있다. |
| 발표 멘트 | “전략과 실행 결과를 분리해서, 어떤 규칙으로 검증했는지 추적할 수 있게 했습니다.” |

### 장면 4. 백테스트 요청

| 항목 | 내용 |
| --- | --- |
| 진입 경로 | 전략 상세 → `백테스트 실행` → `/backtest` |
| 조작 | 대상 전략과 평가 기간을 확인하고 실행 버튼을 누른다. |
| 확인 포인트 | 요청 직후 상태가 `QUEUED` 또는 `RUNNING`으로 보이는 것을 짧게 보여 준다. |
| 발표 멘트 | “백테스트는 요청을 큐에 적재하고 워커가 비동기로 계산합니다. 따라서 요청을 빠르게 접수하고, 계산 상태를 별도로 조회합니다.” |

### 장면 5. 백테스트 결과 분석

| 항목 | 내용 |
| --- | --- |
| 진입 경로 | `/backtest?run={backtestId}` |
| 조작 | 사전에 완료된 실행을 선택해 총 평가자산, 누적 수익률, MDD, 자산 곡선, 체결 내역을 순서대로 본다. |
| 확인 포인트 | 결과를 수익률 하나가 아니라 낙폭·거래비용·체결 흐름까지 함께 해석하는 화면임을 보여 준다. |
| 발표 멘트 | “결과 화면에서는 수익률뿐 아니라 최대 낙폭과 거래 내역을 함께 보며 전략의 수정 방향을 판단합니다.” |

### 장면 6. 모의투자 실행

| 항목 | 내용 |
| --- | --- |
| 진입 경로 | 백테스트 결과 또는 전략 상세 → `모의투자` → `/simulations/{simulationId}` |
| 조작 | 초기 모의자산을 확인하고 시작한다. 준비된 실행 화면에서는 보유 종목, 총 평가자산, 자산 곡선, 체결 원장을 확인한다. |
| 확인 포인트 | 과거 데이터를 대상으로 한 백테스트 이후, 같은 전략을 실제 수집 시세 기반 모의투자로 이어갈 수 있음을 보여 준다. |
| 발표 멘트 | “검증한 전략은 실제 주문 없이 모의투자로 계속 관찰할 수 있습니다. 재선정 시점의 체결과 자산 변화가 기록됩니다.” |

## 4. 시연 중 예외 대응

| 상황 | 대응 |
| --- | --- |
| AI 응답 지연 | 미리 생성해 둔 전략을 전략 목록에서 연다. |
| 백테스트가 오래 걸림 | 새 요청은 상태 변화만 보여 주고, 완료된 실행 이력에서 결과를 연다. |
| Upbit 현재가 미수신 | 결과·체결·자산 곡선 중심으로 설명하고 실시간 가격은 보조 요소로만 다룬다. |
| 모의투자 신규 체결 없음 | 체결 이력이 있는 준비된 실행을 열어 재선정·체결 원장을 설명한다. |
| 로그인 세션 만료 | 시연 시작 전 새 창에서 SSO 로그인을 다시 확인한다. |
