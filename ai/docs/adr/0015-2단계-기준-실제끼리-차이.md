# ADR-0015. 2단계 확인은 실제 데이터 앞뒤 절반의 차이를 허용 범위로 삼는다

- 상태: 채택
- 날짜: 2026-09-15
- 관련: ADR-0011, ADR-0012
- 대체: ADR-0012의 2단계 통과 기준

## 배경

- ADR-0012 2단계는 생성 데이터 분포가 실제 분포와 KS 검정(유의수준 1%)에서 구분되지 않아야 통과였다. 표본이 클수록 임계값이 작아져서, 값이 수천 개인 이음매 지표는 아주 작은 차이도 실패로 나온다 (2026-09-15 확인: 이음매 거래량 변화 KS 0.136, 임계값 0.054).
- ADR-0012는 "통과 기준은 실제 데이터끼리의 차이로 정한다"는 원칙을 세웠지만, 2단계는 이 원칙 대신 검정을 썼다.
- 같은 구간(2019-10-07 ~ 2021-10-04, 10종목)을 1년차와 2년차로 나눠 보면, 실제 시장끼리도 월 변동성, 주 수익률 자기상관, 최대 낙폭 분포가 크게 다르다.

## 결정

- 지표마다 실제 값을 시간순으로 앞 절반과 뒤 절반으로 나눠, 두 묶음의 KS 거리를 허용 범위로 삼는다. 생성 데이터와 실제의 KS 거리가 허용 범위 이하면 통과다.
- 긴 흐름 지표(주 수익률 자기상관, 월 변동성, 최대 낙폭)는 실제 18주 구간을 시작 시각순으로 나눈다. 이음매 지표는 실제 이음매 시각순으로 나눈다.
- 봉 검사는 그대로 전수 위반 0건이다.

## 검토한 대안

- **KS 검정을 유지한다.** 표본 수가 판정을 좌우한다.
- **생성 데이터 중앙값이 실제 분포의 25~75% 안에 들면 통과.** 설명은 쉽지만, 이 데이터에서는 다섯 지표가 모두 여유 있게 통과해 걸러내는 힘이 없다.
- **사람이 정한 고정 허용값.** 값의 근거를 설명할 수 없다 (ADR-0012 검토한 대안).
- **이음매에서 직전 주와 변동성 수준이 같은 주를 고른다 (ADR-0012 "실패하면" 표의 이음매 조정).** 주간 1시간 수익률 표준편차가 풀 중앙값보다 낮은지로 두 수준을 나눠 실험했다(커밋 `9a2d791`, 되돌림 `ca73f91`). 이음매 변동성 변화는 0.094에서 0.084로 조금 줄었지만 허용 범위를 여전히 넘었고, 이음매 거래량 변화는 0.136에서 0.145로 멀어졌다. 대신 긴 흐름이 실제보다 조용해졌다(월 변동성 KS 0.222 → 0.345, 생성 중앙값 0.275 → 0.226, 실제 0.312). 채택하지 않았다.
