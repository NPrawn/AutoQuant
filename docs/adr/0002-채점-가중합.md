# ADR-0002. 변조 데이터 점수와 장세 점수를 가중합한다

- 상태: 채택
- 날짜: 2026-09-14
- 관련: ADR-0001, ADR-0003

## 배경

ADR-0001의 두 데이터를 채점에 넣는 방법은 두 가지다.

- **A.** 변조 데이터로 순위를 매기고, 장세 3개는 실격 기준만 보는 통과/실격 게이트로 쓴다.
- **B.** 두 데이터 모두 점수를 내서 가중합한다.

## 결정

B를 택한다.

```
총점 = w × 수익률 점수 + (1 − w) × 안정성 점수
```

점수 정의는 ADR-0003에 있다. `w`는 아직 정하지 않았고, 시뮬레이션(ADR-0007)에서는 0.5로 둔다.

실격 규칙은 화면 설계 `31-대회 상세`를 따라 데이터셋마다 적용한다. 한 데이터셋에서라도 구간 수익률이 -30% 미만이거나 최대 낙폭이 50%를 넘으면 순위에서 뺀다.

## 검토한 대안

- **A. 장세를 게이트로만 쓴다.** 장세 성적이 통과 여부로만 남아서, 장세에서 얼마나 잘 버텼는지가 순위에 들어가지 않는다.

## 결과

- 하락장 강도가 실격자 수를 크게 좌우한다. 1분봉 시제품 하락장(목표 -25%)에서는 30종목 균등 보유가 -26.5%였고, 30종목 중 9개가 -30% 아래였다. 강도는 ADR-0009에서 목표 범위로 조정한다.
- `w`를 정해야 한다. 시뮬레이션 결과 분포를 보고 정한다.
