# 설계 결정 기록 (ADR)

여러 모듈에 걸친 설계 결정을 하나씩 기록한다. 모듈 안에서 끝나는 결정은 각 모듈 문서에 둔다 (예: AI 서버는 `ai/docs/DECISIONS.md`, 대회 데이터 생성기는 `ai/docs/adr/`).

## 규칙

- 결정 하나에 파일 하나. 파일명은 `NNNN-제목.md`.
- 상태는 `제안` → `채택` 또는 `기각`. 채택한 결정을 바꿀 때는 파일을 고치지 않고 새 ADR을 쓴 뒤, 옛 ADR 상태를 `대체됨 (ADR-NNNN)`으로 바꾼다.
- 버린 대안과 그 이유를 반드시 남긴다. "왜 A가 아니라 B인가"가 나중에 가장 먼저 사라진다.
- 수치는 어디서 측정했는지 같이 적는다.

## 형식

```markdown
# ADR-NNNN. 제목

- 상태: 제안 | 채택 | 기각 | 대체됨 (ADR-NNNN)
- 날짜: YYYY-MM-DD
- 관련: ADR-NNNN

## 배경
## 결정
## 검토한 대안
## 결과
```
