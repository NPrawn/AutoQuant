# ADR-0010. 대회 데이터는 대회를 열 때 한 번 만들어 마감까지 고정한다

- 상태: 채택
- 날짜: 2026-09-14
- 관련: ADR-0001, ADR-0006, ADR-0011

## 배경

- 2018~2025 실제 데이터는 전부 연습 백테스트에 공개된다. 공개하지 않은 실제 구간은 없다.
- 대회 데이터를 언제 만들고 얼마나 오래 쓰는지에 따라 두 방식이 있다.
  - **A.** 대회마다 한 번 만들어 그 대회 동안 고정하고, 다음 대회는 새로 만든다.
  - **B.** 한 번 만든 장을 여러 대회에서 계속 쓴다.
- 화면 설계는 "채점용 장세는 마감 후 공개"라고 적고 있다.

## 결정

A를 택한다.

| 데이터 | 만드는 시점 | 마감 전 | 마감 후 |
|---|---|---|---|
| 연습 | 실제 2018~2025 전체, 만들지 않음 | 공개 | 공개 |
| 일반장·장세 3개 | 대회를 열 때 ADR-0011로 한 번 생성, 마감까지 고정 | 비공개 | 뽑은 주 목록, 순서, 시드, 데이터 공개 |
| universe | 대회를 열 때 정함 | 공개 | 공개 |

- 대회 진행 중에는 대회 데이터로 낸 점수를 보여 주지 않는다. 참가자가 점수를 보고 제출을 고치며 고정된 장에 맞춰 가는 통로를 막는다.
- 다음 대회는 새 시드로 새로 만든다.

## 검토한 대안

- **B. 한 장을 여러 대회에서 계속 쓴다.** 후보를 여러 개 만들어 사람이 직접 고를 수 있고 대회끼리 성적을 비교할 수 있다. 대신 데이터를 계속 비공개해야 하고, 점수만 공개해도 대회를 거듭하며 참가자가 고정된 장에 맞춰 간다.
- **공개하지 않은 실제 구간으로 채점한다 (이전 제안).** 실제 데이터를 전부 공개하므로 성립하지 않는다.

## 2026-09-16 개정 — 내 성적과 순위는 마감 전에 공개한다

점수가 절대값이 되면서(ADR-0003 개정) 제출이 채점되는 대로 점수를 낼 수 있게 됐다. 제출한 사람이 마감까지 아무것도 못 보는 것은 쓰기 나쁘다.

- 제출·교체하면 그 자리에서 데이터셋 4벌을 돌린다. 백테스트가 끝나면 점수와 순위가 나온다.
- 마감 전 순위는 그때까지 채점된 제출 사이의 자리라 잠정이다. 마감 때 그대로 확정된다.
- **채점용 데이터의 출처는 그대로 마감 후에만 공개한다.** 뽑은 주 목록, 시드, 원본 구간은 마감 전에 알면 원본 구간을 역산해 맞출 수 있다.
- 대가: 참가자가 자기 성적을 보고 전략을 고쳐 다시 낼 수 있다(제출 5회). 제출 횟수를 줄일지는 대회 기능 설계 12절에서 정한다.

## 결과

- 마감 후 데이터를 공개해도 다음 대회에 영향이 없다. 다음 대회는 새로 뽑은 주로 만든다. 같은 주가 다시 뽑힐 수는 있지만 앞뒤에 오는 주가 달라진다.
- 대회마다 생성, 검증, 적재를 한 번씩 한다 (ADR-0006).
