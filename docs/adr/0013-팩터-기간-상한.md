# ADR-0013. 대회 전략의 팩터 기간은 대회 데이터의 워밍업 안으로 제한한다

- 상태: 채택
- 날짜: 2026-09-14
- 관련: ADR-0005, ADR-0011

## 배경

- 엔진은 평가를 시작하기 전에 `팩터 최대 기간 + 1`개의 캔들을 요구한다 (`BacktestWarmupCandleCountResolver`). 캔들이 부족한 종목은 빠지고, 모든 종목이 부족하면 백테스트가 실패한다.
- 대회 데이터는 워밍업 5주와 평가 13주로 이루어진다 (ADR-0011). 워밍업 캔들은 1시간봉 840개, 4시간봉 210개, 일봉 35개다.
- 연습 백테스트는 8년치 실제 데이터를 쓰기 때문에 일봉 50·120·200일 같은 긴 기간도 계산된다.

## 결정

- 대회는 제공한 데이터 안에서만 한다. 워밍업은 5주로 유지한다.
- timeframe별 팩터 기간 상한은 `워밍업 캔들 수 − 1`이다.

  | timeframe | 상한 | 달력 기준 |
  |---|---|---|
  | 1H | 839 | 약 35일 |
  | 4H | 209 | 약 35일 |
  | 1D | 34 | 약 35일 |

- 상한은 대회 공지에 적고, 참가자가 이 안으로 전략을 조정한다.
- 상한을 넘는 전략은 제출할 때 막는다.

## 검토한 대안

- **워밍업을 30주로 늘린다.** 일봉 200일 전략까지 돌아가지만 데이터셋이 43주로 길어지고 블록 풀에서 뽑아야 할 주가 늘어난다. 대회는 정해진 데이터 안에서 하고 참가자가 전략을 맞추면 된다고 판단해 택하지 않았다.
- **상한을 넘는 전략도 받고 백테스트에서 실패시킨다.** 캔들 부족으로 실패해 실격되는데, 참가자는 마감 뒤에야 이유를 알게 된다.

## 결과

- 연습에서는 되는 긴 기간 전략(일봉 35일 이상)을 대회에는 제출할 수 없다. 대회 화면과 규칙에 상한을 분명히 보여 줘야 한다.
- 제출 검증은 백엔드와 프론트에 요청한다.
- 워밍업 주 수를 바꾸면 상한도 같이 바뀐다. 상한은 대회 데이터 manifest에 기록한다.
- 검증 실험의 전략 세트(과적합 탐색 포함)도 이 상한 안에서 만든다.
