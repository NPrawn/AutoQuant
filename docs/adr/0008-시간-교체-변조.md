# ADR-0008. 변조는 시간 교체 방식으로 하고 실제 데이터끼리의 차이로 검증한다

- 상태: 기각 (ADR-0011로 대체)
- 날짜: 2026-09-14
- 관련: ADR-0001, ADR-0004, ADR-0005, ADR-0011

> 기각 이유: 노이즈 계열 변조(시간 교체, 가우시안 가산, 일·주 끝점 고정)는 "얼마나 흔들었고 값이 이상하지 않은가"를 통계로 증명해야 해서 참가자와 심사위원에게 설명하기 어렵다. 대회 데이터는 실제 주를 뽑아 새 순서로 잇는 방식(ADR-0011)으로 방향을 바꿨다.

## 배경

1분봉 시제품은 실제 로그 수익률에 가우시안 노이즈를 더했다. 이 방식을 `r' = a·r + √(1−a²)·σ·ε`로 정리해도 세 가지 성질이 망가진다.

- **꼬리가 얇아진다.** 독립 가우시안을 섞으면 초과 첨도가 `a⁴`배가 된다. `a = 0.8`이면 41%로 줄어 코인 특유의 급등락이 사라진다.
- **종목 간 상관이 줄어든다.** 종목마다 노이즈가 독립이라 상관이 `a²`배, 64%로 떨어진다.
- **변동성 군집이 약해진다.** 독립 노이즈에는 "큰 변동 뒤에 큰 변동" 성질이 없다.

"이상한 값이 아닌가"를 판단할 기준도 필요하다. 허용 범위를 사람이 임의로 정하면 심사에서 근거를 댈 수 없다.

## 결정

### 변조: 시간 교체

각 시간 `t`마다 확률 `p`로 수익률을 다른 시간 `s`의 것으로 바꿔 끼운다.

```
σ[t] = 종목별 |수익률|의 지수이동평균 (반감기 24시간)
z[s] = r[s] / σ[s]                 # s 시점의 표준화 수익률

확률 p:      r'[t] = σ[t] · z[s]   # s는 무작위, 30종목 공통
확률 1 − p:  r'[t] = r[t]
```

- `s`를 전 종목에 공통으로 써서 종목 간 상관을 유지한다.
- 수익률을 원본 분포에서 가져오므로 꼬리가 유지되고, `σ[t]`로 스케일하므로 변동성 군집이 유지된다.
- 봉 모양(시가·고가·저가의 종가 대비 비율)과 거래량도 `s`에서 가져온다. 거래량은 두 시점의 주변 거래량 수준 차이만큼 보정한다. 큰 수익률에 작은 거래량이 붙는 모순이 생기지 않고, 거래량 팩터가 실제 데이터와 같은 종목을 고르는 통로도 막힌다.
- 거래대금은 원래 거래대금에 `새 종가 / 원래 종가`를 곱한다.
- 가격은 호가 단위에 맞춘다. 호가 단위는 원본에서 가격대별로 실제 관측한 값으로 표를 만든다. 시제품의 gcd 방식은 기간이 길면 호가 정책 변경 때문에 틀린다.
- 시드가 같으면 결과 파일 해시가 같아야 한다.

`p = 0.2`를 제안한다. 실제 데이터와의 1시간 수익률 상관은 `1 − p = 0.8`이다. 가격 경로는 실제에서 점점 벌어지며, 로그 괴리의 표준편차는 `√(2pT)·σ`다. 92일(2,208시간), 1시간 변동성 1%면 약 21%다.

### 검증: 3단계

허용 범위는 실제 데이터끼리의 차이로 정한다. 예를 들어 실제 두 구간 사이에서 첨도가 ±30% 다르다면, 생성 데이터와 실제 데이터의 차이도 그 안에 들어야 한다.

| 단계 | 검사 | 어기면 |
|---|---|---|
| L1 행 | 가격 > 0, 저가 ≤ min(시가, 종가), 고가 ≥ max(시가, 종가), 호가 단위, 타임스탬프가 원본과 같음, `거래대금 ÷ 거래량`이 [저가, 고가] 안, 4시간봉·일봉이 1시간봉 재집계와 같음 | 생성 실패 |
| L2 종목 분포 | 1시간 변동성, 첨도, 수익률 자기상관(≈0), `\|r\|` 자기상관(변동성 군집), 99.9% 분위수와 최대 `\|r\|`, 거래량-변동성 상관, 종목 간 평균 상관 | 실제끼리 차이 범위를 벗어나면 실패 |
| L3 경로 | 실제와의 1시간 상관 ≈ `1 − p`, 누적 괴리가 이론값 범위 안 | 실패 |

심사 대비로, 실제 구간과 생성 구간을 섞어 간단한 분류기로 구분해 보는 검사를 나중에 더할 수 있다. 정확도가 50% 근처면 구분할 수 없다는 근거가 된다.

## 검토한 대안

- **가우시안 노이즈를 더한다 (1분봉 시제품).** 위 세 성질이 망가진다.
- **앵커형 변조 (일·주 단위 끝점은 실제와 같게 고정).** 가격 경로가 크게 벌어지지 않지만, 일봉 전략은 사실상 실제 데이터를 그대로 본다.

## 결과

- 시간의 `1 − p`(80%)는 수익률이 실제와 같다. 가격 수준은 계속 벌어져서 특정 가격이나 기간 팩터 값을 외워 맞출 수는 없지만, 시간 단위 패턴 일부는 남는다.
- 거래 없는 시간이 종목마다 달라서, `s`에 캔들이 없는 종목이 있으면 `s`를 다시 뽑는다.
- `p`는 시뮬레이션(ADR-0007)에서 실제 순위와 변조 순위의 상관을 보고 조정한다.
