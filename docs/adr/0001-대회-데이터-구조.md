# ADR-0001. 연습은 실제 과거 데이터, 채점은 변조 데이터와 장세 데이터

- 상태: 채택
- 날짜: 2026-09-14
- 관련: ADR-0002, ADR-0010, ADR-0011

## 배경

코인 과거 가격은 누구나 내려받을 수 있다. 실제 과거 데이터로 대회를 채점하면 참가자가 그 구간에 맞춰 전략을 외워 맞출 수 있다.

화면 설계 v1의 `30-대회 목록`, `31-대회 상세`는 연습용도 "AI로 만든" 상승장·하락장·횡보장 3개로 그렸다. 이렇게 하면 연습용과 채점용 합성 데이터를 두 벌 만들어야 하는데, 1분봉 시제품에서 시드만 바꿔 두 벌을 만들었더니 1분 수익률 상관이 0.73~0.79로 남았다. 두 벌이 거의 같아서 분리한 의미가 없었다.

## 결정

- 연습은 기존 백테스트 기능 그대로 실제 과거 캔들로 돌린다. 2018~2025 실제 데이터는 전부 연습에 공개한다.
- 대회 채점에는 두 가지 데이터를 쓴다.
  1. 연습에 쓰는 실제 과거 데이터를 조작해, 누구도 백테스트해 본 적 없게 만든 데이터 (일반장)
  2. 상승장·하락장·횡보장 데이터 3개
- 조작 방식은 ADR-0011에 있다.

## 검토한 대안

- **연습도 합성 장세로 한다 (화면 설계 v1).** 연습 데이터가 합성이라 실제 시장에서 전략을 다듬을 수 없고, 연습용과 채점용을 따로 만들어도 위 측정처럼 잘 갈라지지 않는다.

## 결과

- 화면 설계 `30-대회 목록`, `31-대회 상세`의 "이번 회차 장세 (연습용)" 영역을 고쳐야 한다.
- 실제 데이터를 전부 공개하므로, 공개하지 않은 실제 구간에 기대는 채점 방식은 쓸 수 없다. 조작만으로 "본 적 없는 데이터"를 만들어야 한다 (ADR-0010, ADR-0011).
