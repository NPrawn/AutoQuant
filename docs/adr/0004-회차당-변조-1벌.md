# ADR-0004. 회차당 변조 데이터는 1벌이다

- 상태: 채택
- 날짜: 2026-09-14
- 관련: ADR-0008

## 배경

변조 데이터 한 벌은 무작위 경로 하나다. 1분봉 시제품에서 잰 변조 데이터와 실제 데이터의 1시간 수익률 상관은 0.78이었다. 1시간 수익률 움직임의 약 39%가 노이즈라는 뜻이라, 어떤 경로가 뽑혔는지가 순위에 섞인다.

화면 설계 기준 참가자는 1,284팀이다.

## 결정

회차마다 변조 데이터를 1벌만 만든다. 팀당 백테스트는 4회(변조 1 + 장세 3)다.

## 검토한 대안

| 벌 수 | 팀당 백테스트 | 1,284팀 합계 | 판단 |
|---|---|---|---|
| **1벌** | 4회 | 5,136회 | 채택 |
| 10벌 평균 | 13회 | 약 16,700회 | 경로 운이 대부분 상쇄되지만 채점 부하가 3배 이상 |
| 1,000벌 (judge-plan 원안) | 1,003회 | 약 128만 회 | 마감 후 채점 시간 안에 끝낼 수 없다 |

## 결과

경로 운을 평균으로 상쇄할 수 없다. 운의 비중은 변조 강도가 직접 정하므로, 변조는 약하게 잡는다 (ADR-0008의 `p`).
