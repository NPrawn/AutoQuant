# 노코드 주식 자동매매 / 투자전략 플랫폼

## 1. 프로젝트 한 줄 소개

**코딩 없이 사용자가 직접 주식 투자 전략을 만들고, 과거 시장 데이터로 백테스트한 뒤 AI가 시장 국면과 전략 특성을 분석하여 실제 시세 기반 모의투자까지 수행할 수 있는 투자전략 플랫폼**

---

## 2. 왜 이 프로젝트를 하려는가?

개인 투자자가 알고리즘 투자나 자동매매 전략을 직접 만들어보려면 Python 등의 프로그래밍 지식과 금융 데이터 처리 경험이 필요합니다.

하지만 실제 투자 아이디어는 비교적 간단한 규칙으로 표현되는 경우가 많습니다.

예를 들어,

> **"RSI가 30 이하이고 단기 이동평균선이 장기 이동평균선을 돌파하면 매수한다."**

와 같은 전략입니다.

이러한 투자 아이디어를 코드를 작성하지 않고 직접 구성하고, 실제 과거 시장에서 해당 전략이 어떤 성과를 냈는지 검증할 수 있도록 합니다.

또한 단순히 전체 기간 수익률만 보여주는 것이 아니라,

> **"이 전략은 어떤 시장에서는 잘 작동하고, 어떤 시장에서는 위험한가?"**

를 실제 금융 데이터 기반 AI 분석을 통해 보여주는 것을 목표로 합니다.

### 해결하고 싶은 문제

> **"프로그래밍 지식이 없는 사용자도 자신만의 투자 전략을 만들고, 실제 시장 데이터를 기반으로 전략의 성과와 위험을 검증할 수 없을까?"**

## 4. 주요 기능

### 4.1 노코드 투자전략 생성

사용자가 코드를 작성하지 않고 조건을 조합하여 투자전략을 생성합니다.

- 투자 대상 종목 선택
- RSI / 이동평균 / 거래량 / 변동성 등 지표 선택
- `>`, `<`, `>=`, `<=` 조건 설정
- AND / OR 조건 조합
- 매수 / 매도 조건 설정
- 주문 금액 또는 비율 설정

**예시**

```text
RSI <= 30
AND
MA5 > MA20

THEN

보유 현금의 20% 매수
```

### 4.2 Backtest Engine

사용자가 만든 전략을 실제 과거 주가 데이터에서 실행합니다.

- 과거 시장 데이터 조회
- 투자전략 조건 평가
- 가상 주문 생성
- 체결 처리
- 포트폴리오 관리
- 거래내역 기록
- 수수료 / 슬리피지 반영

**결과 지표**

- 누적 수익률
- CAGR
- MDD
- Sharpe Ratio
- 승률
- 거래 횟수
- 변동성

### 4.3 AI ① Market Regime Detection

단순히 전체 백테스트 결과만 제공하지 않고 **과거 시장이 어떤 상태였는지를 데이터 기반으로 분류**합니다.

```text
시장 데이터

가격
거래량
수익률
변동성
추세 지표
시장 지수
금리 등

        ↓

AI / ML Model

        ↓

Market Regime

상승 추세
하락 추세
횡보
고변동성
저변동성
```

이를 Backtest Engine과 결합하여 전략의 시장별 성과를 분석합니다.

**예시**

```text
RSI Reversal Strategy

전체       +18.4%

상승장     +25.1%
횡보장     +12.3%
하락장     -14.8%
고변동성   -19.2%
```

이를 통해 단순히

> "수익률이 높은 전략"

이 아니라,

> **"어떤 시장에서 강하고 어떤 시장에서 위험한 전략인지"**

를 분석할 수 있습니다.

### 4.4 AI ② Strategy Analysis / Recommendation

백테스트를 통해 생성되는 전략 데이터를 이용하여 전략의 특성을 분석합니다.

각 전략을 다음과 같은 Feature로 표현할 수 있습니다.

```text
Strategy Feature

CAGR
MDD
Sharpe Ratio
Volatility
Win Rate
Turnover
Trade Count
상승장 수익률
하락장 수익률
횡보장 수익률
```

이 데이터를 기반으로 다음 기능을 수행합니다.

- 전략 유형 분류
- 유사 전략 탐색
- 전략 Clustering
- 사용자 투자성향 기반 전략 추천

예를 들어 사용자가

> **"수익률이 조금 낮더라도 손실폭이 작은 전략"**

을 선호한다면, MDD와 변동성이 낮은 전략을 중심으로 추천할 수 있습니다.

### 4.5 실시간 모의투자

백테스트가 끝난 전략을 실제 시장 데이터 기반 모의투자로 실행합니다.

```text
실시간 시장 데이터
        ↓
Strategy Engine
        ↓
조건 충족
        ↓
가상 주문 생성
        ↓
Order Engine
        ↓
가상 체결
        ↓
Portfolio 반영
```

- 실제 시장 시세 기반 모의투자
- 전략 자동 실행
- 가상 계좌 관리
- 보유 종목 관리
- 실시간 수익률 제공

### 4.6 전략 공유

사용자가 만든 전략을 다른 사용자와 공유할 수 있습니다.

- 전략 공개
- 전략별 백테스트 결과 확인
- 시장 국면별 성과 확인
- 전략 복사
- 조건 수정 후 재검증
- 전략 비교
- 위험 대비 수익률 기반 랭킹

## 6. 프로젝트의 중심은 LLM이 아니라 투자 시스템 + 금융 AI

이 프로젝트에서 AI가 투자전략을 대신 만들어주거나 단순히 투자 질문에 답변하는 것이 핵심이 아닙니다.

핵심은 다음 구성요소를 하나의 투자 시스템으로 구축하는 것입니다.

```text
Strategy Engine
+
Backtest Engine
+
Order / Execution System
+
Market Regime AI
+
Strategy Analysis AI
```

따라서 일반적인

> **"금융 데이터 + GPT API"**

형태의 프로젝트와 차별화하고자 합니다.

AI는 단순한 자연어 설명이 아니라 **실제 시장 데이터와 백테스트 결과를 분석하는 역할**을 담당합니다.

대략적인 개발 비중은 다음과 같이 생각하고 있습니다.

```text
Backend / Trading System       약 50%
AI / Financial Analysis        약 30%
Data Processing                약 20%
```

## 9. 프로젝트에서 보여주고 싶은 결과

단순히

> **"주식 모의투자 서비스를 만들었다."**

또는

> **"AI가 투자전략을 추천한다."**

가 아니라,

> **"사용자가 만든 투자전략을 실제 시장 데이터에서 실행하고, 시장 상황에 따라 전략의 성능이 어떻게 달라지는지 AI를 통해 분석하는 투자전략 검증 시스템을 구현했다."**

를 보여주는 것이 목표입니다.

### 전략 성과 비교 예시

| 전략 | CAGR | MDD | 상승장 | 하락장 | 횡보장 |
| --- | ---: | ---: | ---: | ---: | ---: |
| RSI 반등 | +14.2% | -18.1% | +25.1% | -14.8% | +12.3% |
| MA 추세추종 | +11.8% | -10.4% | +31.2% | -5.1% | -2.4% |
| 단순 보유 | +9.7% | -24.3% | +28.5% | -22.7% | +3.1% |

> ※ 수치는 예시이며 실제 프로젝트에서는 실제 금융 데이터를 기반으로 직접 Benchmark

### 시스템 성능 지표

추가로 다음과 같은 시스템 지표도 측정할 수 있습니다.

- 백테스트 처리시간
- 데이터 규모 증가에 따른 처리시간
- 동시에 처리 가능한 백테스트 수
- 전략 평가 처리량
- 실시간 전략 평가 지연시간
- 주문 중복 / 정합성 테스트
- Kafka Consumer 처리량
- Cache 적용 전후 성능

## 10. 프로젝트의 장점

### 단순 CRUD + GPT 프로젝트와 차별화

LLM이 투자 질문에 답변하는 서비스가 아니라 **실제 투자전략을 실행하고 검증하는 시스템 자체가 핵심 기능**입니다.

AI 기능을 제거하더라도 Strategy Engine, Backtest Engine, Order Engine이라는 독립적인 서비스 가치가 남습니다.

### AI 파트가 실제 금융 데이터를 다룸

AI가 단순히 자연어를 생성하는 것이 아니라 **시장 데이터와 전략 성과 데이터를 직접 분석**합니다.

따라서 Market Regime Detection, Clustering, Recommendation 등의 AI/ML 경험을 가져갈 수 있습니다.

### Backend 경험을 깊게 가져갈 수 있음

단순 CRUD를 넘어 다음과 같은 기술적 문제를 다룰 수 있습니다.

- Strategy Engine
- Backtest Engine
- 주문 / 체결
- Transaction
- 동시성
- 멱등성
- Kafka
- Redis
- 실시간 데이터 처리
- 대용량 데이터 처리

### 결과를 실제 데이터로 검증 가능

과거 시장 데이터가 존재하기 때문에 전략의 성과뿐 아니라 시스템의 처리 성능도 직접 Benchmark할 수 있습니다.

### 금융특화 프로젝트라는 성격이 명확함

주식 시장 데이터, 투자전략, 주문·체결, 포트폴리오, 위험지표 등을 직접 다루기 때문에 금융 도메인 경험을 가져갈 수 있습니다.

## 11. GPT와의 차별점

GPT가 금융 데이터에 접근할 수 있게 되더라도 실제로 전략을 실행하려면 별도의 시스템이 필요합니다.

이 프로젝트에서 만드는 것은 단순한 금융 상담 AI가 아니라,

```text
사용자 / AI Agent
        ↓
Strategy Definition
        ↓
Strategy Engine
        ↓
Backtest Engine
        ↓
Order Engine
        ↓
Portfolio
        ↓
Financial AI Analysis
```

라는 **실행 가능한 투자 인프라**입니다.

따라서 향후 LLM이 발전하더라도 LLM은 플랫폼을 사용하는 하나의 인터페이스가 될 수 있으며, 플랫폼의 핵심인 전략 실행·검증 시스템 자체를 대체하지 않습니다.

## 12. 프로젝트 핵심 문장

> **프로그래밍 지식이 없는 사용자도 자신만의 투자 아이디어를 알고리즘으로 구성하고 검증할 수 있도록 Strategy·Backtest·Order Engine을 구축하고, 실제 금융 데이터 기반 AI를 통해 시장 국면별 전략 성능과 투자전략의 특성을 분석한다.**

### 프로젝트 키워드

`Spring Boot` `Strategy Engine` `Backtesting` `Trading System` `No-Code` `Market Regime Detection` `Machine Learning` `Recommendation System` `Financial Data` `Kafka` `Redis` `Concurrency` `Idempotency` `Real-Time Processing`
